## อัปเดตระบบเดิม

1. แตกชุด Update แล้วคัดลอกไปทับ Repository เดิม เก็บ dist/config.js และค่าหลังบ้านที่ใช้งานอยู่
2. VS Code Terminal รัน npm.cmd run check และ npm.cmd test
3. GitHub Desktop → Commit to main → Push origin แล้วรอ Actions งานใหม่ผ่าน เปิด Pages และ Ctrl + F5
4. ใช้บัญชีเดิม ระบบฐานข้อมูล 1.11.0 รองรับเว็บ 1.12 ไม่มี SQL อัปเกรดสำหรับรุ่นนี้

ชุดนี้รวมไฟล์แก้ CI เรื่องเวลาเซสชัน tests/helpers/auth-session.mjs และการทดสอบสิทธิ์เดิมไว้ครบ รายละเอียดใน docs/CI-FIX-20261030-TH.md

## Excel

ชีตบุคลากร 15 คอลัมน์ ใบรับรอง 10 คอลัมน์ วันที่ พ.ศ. คงรูปแบบเดิม หลายสาขาวิชาใช้ ; คั่น หลายใบรับรองเพิ่มแถวโดยใช้เลขที่ตำแหน่งเดิม เพิ่มรูปถ่ายจากหน้าเว็บหลังมีทะเบียนแล้ว

แม่แบบว่างใน dist ใช้รายการตั้งค่าที่ตรวจเมื่อ 30 ตุลาคม 2569 หากแอดมินเพิ่มสถานศึกษาหรือตำแหน่ง ให้ใช้ปุ่มดาวน์โหลดแม่แบบในเว็บเพื่อรับรายการล่าสุด ไฟล์ที่เก็บไว้ในเครื่องไม่เปลี่ยนเอง

ไฟล์ที่มีข้อมูลจริงของผู้ใช้ปรับรายการเลือกและเก็บค่าทุกช่องของทั้ง 13 รายไว้ แต่แยกส่งจากโค้ดสาธารณะ ชุด Full / Update / Complete บรรจุเฉพาะแม่แบบว่างกับตัวอย่างสมมติ

## รูปถ่ายและเซสชัน

รูปถ่าย เพิ่ม–เปลี่ยน–ลบ พร้อมตรวจและยืนยันก่อนบันทึก ยังคงทำงานตามสิทธิ์ รายชื่อในหน่วยงานเรียงผู้บริหารถึงเจ้าหน้าที่และชื่อไทย เข้าสู่ระบบครั้งเดียวระหว่างเปลี่ยนเมนู ผู้เยี่ยมชมดูเฉพาะสถิติรวม รายละเอียดต้องเข้าสู่ระบบ การโหลดหน้าใหม่หรือปิดแท็บต้องเข้าสู่ระบบใหม่

## หลังบ้าน

supabase/schema.sql เต็มสำหรับติดตั้งใหม่ยังเป็น schema 1.11.0 Edge Functions hr-bridge / hr-accounts ใช้การเชื่อมต่อเดิม Apps Script ให้โค้ดครบและระบุ app_version 1.12.0 ในไฟล์สำรอง ถ้าวางโค้ด Apps Script ใหม่ให้ Deploy → Manage deployments → New version เพื่อใช้ URL เดิม

ตั้งค่าใหม่และสร้าง admin เฉพาะโครงการใหม่ตามคู่มือ ค่า service_role และ BRIDGE_SECRET เก็บเฉพาะหลังบ้าน หน้าเว็บใช้ Project URL กับ publishable key
