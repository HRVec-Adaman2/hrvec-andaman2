## ระบบเดิม 1.10

1. ใน Supabase SQL Editor ตรวจ select public.hr_schema_version(); ถ้ายังเป็น 1.10.0 รัน supabase/upgrade-v1.11.sql ทั้งไฟล์ ถ้าเป็น 1.11.0 แล้วข้ามได้
2. แตกชุด Update แล้วคัดลอกไปทับ Repository เดิม เก็บ dist/config.js และค่าหลังบ้านที่ถูกต้องไว้
3. ใน VS Code Terminal รัน npm.cmd run check และ npm.cmd test
4. GitHub Desktop → Commit to main → Push origin แล้วรอ Actions สีเขียว เปิด Pages และ Ctrl + F5
5. ใช้ admin เดิม ไม่สร้าง admin ใหม่ ไม่รีเซ็ตรหัส และไม่นำเข้ารายชื่อเดิมซ้ำ

ฐานข้อมูลโครงการ HR oftlfxiywhtoftxluviv อัปเกรดเป็น 1.11.0 แล้วเมื่อ 30 ตุลาคม 2569 ตรวจข้อมูล 13 รายและ fingerprint ตรงกับก่อนอัปเกรด การเผยแพร่ Site ไม่เปลี่ยน GitHub ของผู้ใช้โดยอัตโนมัติ

Google Apps Script ให้ Code.gs และ appsscript.json ครบในชุดนี้ รุ่นนี้เปลี่ยนเพียง app_version ของไฟล์สำรอง ระบบ Google เดิมที่ทำงานได้ใช้ต่อได้ หากนำโค้ดไปแทน ให้ Deploy → Manage deployments → New version เพื่อใช้ URL เดิม Edge Functions เดิมไม่ต้อง Deploy ใหม่เพื่อรับการเปลี่ยนแปลงรุ่นนี้

## รูปถ่ายและสิทธิ์

หน้าเว็บรับ JPEG / PNG / WebP ต้นฉบับไม่เกิน 10 MB ย่อเป็น JPEG ด้านยาวไม่เกิน 320 พิกเซล เก็บใน personnel.avatar_data ภายใต้ RLS ประวัติเก็บ hash ของรูป ไม่เก็บ base64 ซ้ำ สำรอง JSON รวมรูป ส่วนสำเนา Sheets ไม่คัดลอกภาพลงเซลล์

admin จัดการทุกคน บุคลากรจัดการรูปตนเอง เจ้าหน้าที่หน่วยงานต้องมี contact_write หรือ personnel_write ของบุคคลนั้น ผู้มีสิทธิ์อ่านอย่างเดียวเห็นรูปแต่ไม่มีปุ่มแก้ไข ต้องทบทวนและระบุเหตุผลก่อนบันทึก ตรวจ revision เพื่อป้องกันเขียนทับ

การเปลี่ยนเมนูไม่ขอรหัสซ้ำ การโหลดหน้าใหม่ ปิดแท็บ หรือออกจากระบบต้องเข้าสู่ระบบใหม่ ไม่เก็บรหัสผ่านหรือ token ใน localStorage ของระบบจริง สิทธิ์แต่ละบทบาทและการบังคับเปลี่ยนรหัสครั้งแรกยังทำงาน

## สถิติสาธารณะ

public.hr_public_overview เป็น SECURITY INVOKER เรียกตัวรวมผลใน schema ที่ไม่เปิด Data API ส่งเฉพาะยอดและจำนวนแยกหน่วยงาน ไม่ส่งชื่อ เลขที่ตำแหน่ง รูป ข้อมูลติดต่อ รายละเอียดใบรับรองหรือไฟล์ ไม่เปิดสิทธิ์ตารางบุคลากรให้ anon

## Excel

ใช้แม่แบบเดิม 1.10 ต่อได้ บุคลากร 15 คอลัมน์ ใบรับรอง 10 คอลัมน์ วันเป็น พ.ศ. หลายสาขาวิชาใช้ ; คั่น หลายใบรับรองเพิ่มแถวในชีตใบรับรองโดยใช้เลขที่ตำแหน่งเดิม ไม่เพิ่มคอลัมน์ เพิ่มรูปผ่านหน้าเว็บหลังนำเข้า
