# HRVec-Andaman2 1.12.1 — แก้แม่แบบที่ดาวน์โหลดจากเว็บ

วันที่ 30 ตุลาคม 2569 ใช้ฐานข้อมูลและ Apps Script ชุดเดิม

## สิ่งที่ปรับ

- แก้ตัวสร้างไฟล์ที่ปุ่มดาวน์โหลดใช้งาน โดยอ้างอิงรายการเลือกผ่านชื่อช่วงข้อมูลระดับ Workbook (Named ranges)
- หน่วยงาน ตำแหน่ง วิทยฐานะ วุฒิการศึกษา ตำแหน่งทางวิชาการ ด้านงาน และประเภทใบรับรองใช้รายการปัจจุบันเดียวกับฟอร์ม
- ฝ่ายเลือกตามประเภทหน่วยงาน ส่วนกลางสถาบันหรือสถานศึกษา ผู้อำนวยการเว้นฝ่ายว่างได้
- เมื่อเปิดไฟล์ เลือกเซลล์ C2 ในชีต บุคลากร ไว้ให้ และใช้สีฟ้ากับช่องรายการเลือก
- ในชีต ใบรับรองวิชาชีพ เริ่มเลือกประเภทที่ B2 ส่วน A เลือกเลขที่ตำแหน่งหลังกรอกชีต บุคลากร
- เลขที่ตำแหน่ง เบอร์โทรศัพท์ และช่องวันที่เตรียมเป็นข้อความครบช่วง 500 คน / 5,000 ใบ
- เปลี่ยนชื่อไฟล์จากปุ่มเป็น HRVec-Andaman2-v1.12.1-Personnel-Template.xlsx
- โหลดโมดูลที่แก้ไขด้วยเลขรุ่น เพื่อให้เบราว์เซอร์ขอไฟล์ใหม่
- แนบลิงก์ดาวน์โหลดเข้าหน้าเอกสารก่อนเริ่มบันทึก และเก็บ Blob URL ไว้ 60 วินาทีเพื่อรองรับหน้าต่าง Save As

## อัปเดต GitHub — ใช้ File Explorer และ Chrome หรือ Edge

1. ดาวน์โหลด ZIP ชุด 1.12.1 แล้วคลิกขวา Extract All / แยกทั้งหมด
2. เปิดโฟลเดอร์ที่แตกไฟล์ จะพบ dist, tests, docs, deployment และ package.json กับ README.md
3. เปิดหน้าหลัก Repository https://github.com/HRVec-Adaman2/hrvec-andaman2 เลือก Code และ Branch main
4. ต้องเริ่มอัปโหลดจากหน้าหลักที่มองเห็นโฟลเดอร์ dist ไม่ใช่เปิดอยู่ภายใน dist
5. เลือก Add file → Upload files แล้วลากโฟลเดอร์ dist, tests, docs, deployment และไฟล์ package.json, README.md จากชุดนี้ลงไปพร้อมกัน
6. อย่าลาก ZIP หรือโฟลเดอร์ชั้นนอกที่ชื่อ HRVec-Andaman2-v1.12.1-Download-Dropdown-Fix ลงไป
7. ตรวจว่ารายการไฟล์แสดงตำแหน่ง dist/app.js, dist/template.js, dist/xlsx-compat.js และ package.json กับ README.md ที่รากโครงการ ไม่เป็น dist/dist
8. ใส่ข้อความ Commit ว่า Fix web template dropdowns v1.12.1 แล้ว Commit changes ลง main
9. หาก GitHub ให้สร้าง Pull request ให้สร้างและ Merge เข้า main
10. เปิด Actions ดูรายการใหม่จาก Commit นี้ รอ Workflow ทำงานสำเร็จ
11. เปิดเว็บไซต์ของคุณ กด Ctrl + F5 หรือเปิด InPrivate / Incognito แล้วเข้าสู่ระบบตามปกติ
12. ท้ายหน้าเว็บต้องแสดง รุ่น 1.12.1 จากนั้นกด ดาวน์โหลดแม่แบบ .xlsx อีกครั้ง

ชุดแก้ไขไม่บรรจุ dist/config.js จึงคงค่าการเชื่อมต่อที่ติดตั้งไว้ ไม่ต้องตั้ง Secrets รัน SQL หรือเผยแพร่ Apps Script ใหม่

## ตรวจรายการใน Microsoft Excel บน Windows

1. เปิดไฟล์ที่ดาวน์โหลดใหม่ ชื่อต้องมี v1.12.1 อย่าเปิดไฟล์ v1.12 ที่ค้างอยู่
2. ถ้ามีแถบ Protected View ให้กด Enable Editing / เปิดใช้งานการแก้ไข สำหรับไฟล์ที่คุณเพิ่งดาวน์โหลดจากระบบของคุณ
3. เปิดชีต บุคลากร ที่แถบชื่อชีตด้านล่าง เลือกเซลล์ C2
4. คลิกลูกศรเล็กทางขวาของเซลล์ หรือกด Alt + ลูกศรลง เพื่อเปิดรายการ
5. ลูกศรแสดงเมื่อเลือกเซลล์ที่มีรายการ ไม่ใช่หน้าต่าง Save As หรือหัวตารางแถว 1

| เซลล์เริ่มต้น | ข้อมูล |
|---|---|
| C2 | หน่วยงาน/สถานศึกษา |
| D2 | ตำแหน่ง |
| E2 | ฝ่าย/ส่วนราชการ ตามหน่วยงานใน C2 |
| G2 | วิทยฐานะ |
| L2 | วุฒิการศึกษาสูงสุด |
| N2 | ตำแหน่งทางวิชาการ |
| O2 | ด้านงานบริหารทั่วไป |
| ใบรับรองวิชาชีพ!A2 | เลขที่ตำแหน่งที่กรอกในชีต บุคลากร |
| ใบรับรองวิชาชีพ!B2 | ประเภทใบรับรอง |

ชื่อบุคลากร เลขที่ตำแหน่ง อีเมล โทรศัพท์ สาขาวิชา และรายละเอียดใบรับรองกรอกตามข้อมูลจริง รายการอ้างอิงว่างสำหรับข้อความส่วนตัว ไม่ใส่รายชื่อหรือข้อมูลติดต่อของผู้อื่นลงแม่แบบว่าง

ถ้าเลือก C2 แล้วยังไม่เห็นรายการ ให้เปิด Excel → Data / ข้อมูล → Data Validation / การตรวจสอบความถูกต้องของข้อมูล ช่อง Allow ต้องเป็น List และเปิด In-cell dropdown แหล่งข้อมูลรุ่นนี้คือ =HRV_school_id

กรอกหลายสาขาวิชาโดยคั่นด้วย ; ส่วนหลายใบรับรองให้เพิ่มแถวในชีต ใบรับรองวิชาชีพ โดยใช้เลขที่ตำแหน่งเดิม

## ผลการตรวจและข้อจำกัด

- npm run check ผ่าน และ npm test ผ่าน 125 รายการ
- เพิ่มการตรวจไฟล์ที่ตัวสร้างของปุ่มดาวน์โหลดส่งออกจริง อ่านกลับด้วย ExcelJS แล้วตรวจชื่อช่วง แหล่งรายการ แถวสุดท้าย การอ้างอิงฝ่ายตามหน่วยงาน วันที่และเลขศูนย์นำหน้า
- ตรวจช่วงรายการของหน่วยงานใหม่และหน่วยงานที่ปิดใช้งาน รวมถึงขอบเขตตามสิทธิ์
- ตรวจหน้าบุคลากรใน Chrome ของสภาพแวดล้อมทดสอบได้ แต่ API เบราว์เซอร์ทดสอบไม่ส่งผลการดาวน์โหลด Blob กลับมา จึงยังยืนยันการรับไฟล์จากเบราว์เซอร์นั้นไม่ได้
- ยังไม่ได้ยืนยันการคลิกรายการใน Microsoft Excel บน Windows ของผู้ใช้ ให้ตรวจตามขั้นตอน C2 ด้านบน
- ไม่ได้นำเข้า แก้ไข หรือลบบุคลากรจริงระหว่างทดสอบ
- ไฟล์แม่แบบที่เก็บใน dist เป็นชื่อคงที่ HRVec-Andaman2-Personnel-Template.xlsx สำหรับการตรวจและแจกไฟล์เดิม ส่วนปุ่มบนเว็บสร้างไฟล์รุ่น 1.12.1 ตามรายการปัจจุบัน
