- สแกนสูตรผิดพลาดด้วย Artifact Tool พบ 0 รายการที่เข้าเงื่อนไข ตรวจภาพภาษาไทยในช่วงที่เปลี่ยนและปรับความสูงแถวรายการฝ่ายให้ข้อความอ่านครบ
- ไฟล์ Excel เดิมเปิดจากต้นฉบับล่าสุดที่ได้รับอนุญาต ตรวจข้อมูลบุคลากร 13 รายและเซลล์ในชีตบุคลากร/ใบรับรองทั้งหมดด้วยตัวอ่านไฟล์ที่ส่งออกซ้ำ ค่าทุกช่องเหมือนเดิม ชื่อและลำดับชีต รวมถึงแถวตรึงยังตรงกัน

ใช้ Artifact Tool ในการแก้ Excel ทั้งสองไฟล์ ไม่ได้นำไฟล์ที่มีรายชื่อจริงเข้าฐานข้อมูลหรือใส่ใน ZIP โค้ด ชุด SQL, สิทธิ์ RLS, Auth และ Edge Functions ไม่เปลี่ยนในรุ่นนี้ ชุดทดสอบ PostgreSQL เดิมและตัวช่วยแก้ CI ยังอยู่ใน workflow

ไม่ได้เปิด native Microsoft Excel บน Windows หรือใช้บัญชีจริงทดสอบ Drive ในรอบนี้ ให้ตรวจการเลือก C2 / D2 / E2 / G2 ใน Excel ของหน่วยงานหลังดาวน์โหลดตามคู่มือ
