# HRVec-Andaman2: อัปเดตระบบให้ตรงกับแม่แบบรุ่น 1.8 ที่ปรับล่าสุด

วันที่ตรวจสอบ 23 ตุลาคม 2569 ระบบใช้ฐานข้อมูลรุ่น 1.9.0 แม่แบบยังคงชื่อไฟล์รุ่น 1.8 ตามที่ส่งให้สถานศึกษา แต่หัวตารางและช่องข้อมูลตรงกับระบบปัจจุบัน

## สิ่งที่ปรับ

- บุคลากร 13 คอลัมน์ และใบรับรอง 10 คอลัมน์ ใช้หัวตารางภาษาไทย
- รองรับ 7 วิทยาลัยและส่วนกลางสถาบัน ฝ่ายสถานศึกษา 4 ฝ่าย และส่วนราชการสถาบัน 5 ส่วนตามรายการในระบบ
- เพิ่มงาน/แผนก/กลุ่มงาน วุฒิสูงสุดและหลายสาขาวิชา รวมทั้งสมรรถนะทางวิชาชีพ สาขาอาชีพ ระดับ และมาตรฐานอ้างอิง
- ผู้อำนวยการเว้นฝ่ายว่างได้ ไม่มีช่องสถานะหรือที่อยู่ในแบบฟอร์มและแม่แบบใหม่
- อ่านหัวตารางเดิมที่ใช้ความหมายเดียวกันได้ และแจ้งชื่อช่องที่แปลงก่อนบันทึก เช่น วันเริ่มรับราชการ เป็น วันเริ่มงาน
- ตรวจหัวตารางซ้ำ เลขที่ตำแหน่งซ้ำ หน่วยงานผิด วันที่ผิด และใบรับรองไม่ครบ พร้อมระบุชีตและแถวที่ต้องแก้
- หน้าตรวจสอบแสดงตำแหน่ง ฝ่าย งาน ประเภทใบรับรอง สาขาอาชีพ ระดับ และมาตรฐาน ก่อนกดยืนยัน

## 2. อัปเดตโค้ดเดิมด้วย ZIP สำหรับอัปเดต

1. ดาวน์โหลดไฟล์ที่ชื่อมีคำว่า Update แล้วคลิกขวาใน File Explorer เลือก Extract All เพื่อแตกไฟล์ไว้อีกโฟลเดอร์หนึ่ง
2. เปิด VS Code เลือก File → Open Folder แล้วเปิดโฟลเดอร์โครงการ HRVec-Andaman2 เดิมที่เชื่อม GitHub อยู่ ต้องเห็น package.json, dist, supabase และ .github อยู่ระดับเดียวกัน
3. สำรองโฟลเดอร์โครงการเดิมไว้นอกโฟลเดอร์ GitHub ก่อนคัดลอกไฟล์
4. เปิดโฟลเดอร์ที่แตก ZIP คัดลอกไฟล์และโฟลเดอร์ทั้งหมดข้างใน ไปวางที่ระดับหลักของโครงการเดิม เลือก Replace the files in the destination เมื่อ Windows ถาม ไม่วางโฟลเดอร์ ZIP ครอบเพิ่มอีกชั้น
5. ZIP สำหรับอัปเดตไม่มี dist/config.js และไม่มีไฟล์ .env จริง จึงคงค่าการเชื่อมต่อและความลับเดิมไว้ มีไฟล์ตัวอย่าง .env.example สำหรับอ้างอิงเท่านั้น
6. ใน VS Code เลือก Terminal → New Terminal ถ้าเป็น PowerShell ใช้คำสั่ง npm.cmd ตามตัวอย่างต่อไปนี้ รันทีละคำสั่ง รอให้เสร็จก่อนรันคำสั่งต่อไป

```powershell
npm.cmd run check
npm.cmd test
```

ผลที่ควรได้: ตรวจไวยากรณ์ผ่าน และการทดสอบ 100 รายการผ่าน ไม่มี fail

7. กด Ctrl + Shift + G เปิด Source Control ตรวจรายการไฟล์ที่เปลี่ยน กด Stage เฉพาะโค้ดและแม่แบบเปล่า
8. พิมพ์ข้อความ Commit เช่น Update Thai personnel template compatibility แล้วกด Commit → Sync Changes
9. เปิด Repository เดิมใน GitHub ด้วย Chrome หรือ Edge ไปที่ Actions แล้วรอรายการ Deploy HRVec-Andaman2 to GitHub Pages เป็นสีเขียว
10. หาก Configure Pages แจ้ง 404 ให้เปิด Repository → Settings → Pages → Build and deployment → Source เลือก GitHub Actions แล้วกลับไป Actions เพื่อ Run workflow อีกครั้ง
11. เปิด Settings → Pages → Visit site แล้วกด Ctrl + F5 เพื่อโหลดไฟล์หน้าเว็บล่าสุด

ZIP สำหรับอัปเดตมีโค้ดหน้าบ้านและหลังบ้านครบตามรุ่นนี้ การคัดลอกไฟล์ SQL ลงโฟลเดอร์โครงการไม่ใช่การรัน SQL และไม่เปลี่ยนข้อมูลในฐานข้อมูลจริง

## 3. ถ้าเว็บ GitHub ยังขึ้นโหมดสาธิต

ใช้ VS Code เปิด deployment/config.production.js ซึ่งมีเฉพาะ Project URL และ Publishable key สาธารณะของโครงการ HR ที่ตรวจสอบแล้ว คัดลอกเนื้อหาทั้งไฟล์ไปแทน dist/config.js แล้วบันทึก Commit และ Sync Changes อีกครั้ง

Project URL ที่ต้องตรงกันคือ https://oftlfxiywhtoftxluviv.supabase.co ห้ามนำ service_role key, BRIDGE_SECRET หรือรหัสผ่านไปใส่ config.js

เมื่อตั้งค่าถูกต้อง หน้าบุคลากรจะขอเข้าสู่ระบบจริง ใช้ชื่อผู้ใช้และรหัสผ่านเดิมของคุณ ไม่สร้าง admin ซ้ำและไม่เปลี่ยนกลับเป็น 123456 จากการอัปเดตครั้งนี้ หากบัญชียังถูกบังคับเปลี่ยนรหัสครั้งแรก ให้ทำขั้นตอนเปลี่ยนรหัสบนหน้าจอให้เสร็จก่อนเปิดข้อมูล

หนึ่งคนกรอกหนึ่งแถวในชีตบุคลากร เริ่มแถว 2 ต้องมีเลขที่ตำแหน่ง ชื่อ-นามสกุล และหน่วยงาน/สถานศึกษา เลือกชื่อหน่วยงานเต็มตามรายการอ้างอิง ผู้อำนวยการเว้นฝ่ายว่างได้ ถ้ามีหลายสาขาวิชาของวุฒิสูงสุด ใช้ ; คั่นในเซลล์เดียวกัน เช่น การบริหารการศึกษา; เทคโนโลยีการศึกษา

ใบรับรองหนึ่งใบกรอกหนึ่งแถวในชีตใบรับรองวิชาชีพ ต้องมีเลขที่ตำแหน่ง ประเภท ชื่อใบรับรอง และหน่วยงานผู้ออก ถ้ามีหลายใบ ให้เพิ่มแถวแล้วใช้เลขที่ตำแหน่งของคนเดิมซ้ำ ไม่เพิ่มคอลัมน์ใบที่ 2 หรือใบที่ 3 และไม่เพิ่มคนเดิมซ้ำในชีตบุคลากร

ใบรับรองสมรรถนะให้กรอกสาขาอาชีพ ระดับสมรรถนะ และมาตรฐานตามเอกสารจริง ช่องที่ไม่ปรากฏในหลักฐานเว้นว่างได้ เลขที่ตำแหน่ง โทรศัพท์ และเลขที่ใบรับรองให้ใช้รูปแบบ Text เพื่อรักษาศูนย์นำหน้า วันที่ใช้ YYYY-MM-DD ค.ศ. หรือวันที่ Excel ตามตัวอย่าง ไม่ใช้ปี พ.ศ.

ถ้าไฟล์เก่ายังมีคอลัมน์ที่อยู่ ต้องลบทั้งคอลัมน์ก่อนนำเข้า รุ่นปัจจุบันไม่รับคอลัมน์ดังกล่าว แม้เซลล์ข้อมูลว่าง ชีตคำแนะนำ รายการอ้างอิง และตัวอย่างไม่ถูกนำเข้าอัตโนมัติ

## 5. นำเข้าระบบจริง

1. เปิดเว็บไซต์จริงด้วย Chrome หรือ Edge เข้าสู่ระบบด้วยบัญชี admin เดิม หรือเจ้าหน้าที่ที่ได้รับสิทธิ์นำเข้าทั้งหน่วยงาน
2. เปิดข้อมูลบุคลากร → อัปโหลด Excel แล้วเลือกไฟล์ที่กรอกข้อมูลจริงเรียบร้อยแล้ว
3. กดตรวจสอบข้อมูล ตรวจยอดบุคลากร ยอดใบรับรอง หน่วยงาน ฝ่าย งาน วุฒิ และรายละเอียดสมรรถนะในหน้าตรวจสอบ
4. หากมีข้อผิดพลาด ระบบจะไม่แสดงปุ่มยืนยัน ให้แก้ใน Excel บันทึกไฟล์ แล้วเลือกไฟล์ใหม่
5. เมื่อข้อมูลถูกต้อง กดยืนยันบันทึกหนึ่งครั้ง รอข้อความสำเร็จ แล้วตรวจรายชื่อและใบรับรองจากแฟ้มบุคลากร

ระบบบันทึกบุคลากรและใบรับรองเป็นชุดเดียว ถ้ามีข้อผิดพลาดจะไม่บันทึกบางส่วน ไฟล์นี้ใช้เพิ่มคนใหม่ เลขที่ตำแหน่งที่มีอยู่แล้วต้องแก้ไขจากแฟ้มบุคลากร ไม่ใช้ Excel เขียนทับรายการเดิม รองรับสูงสุด 500 คน 5,000 ใบ และ 100 ใบต่อคนต่อครั้ง ไฟล์ไม่เกิน 5 MB

## 6. ผลตรวจและขอบเขตการทดสอบ

- ตรวจไวยากรณ์ JavaScript และการทดสอบอัตโนมัติ 100 รายการ รวมไฟล์ XLSX จริง การอ่านหัวตารางเดิม การเชื่อมหลายใบ หน้าตรวจสอบ และการยืนยันบันทึกในโหมดสาธิต
- ตรวจฐานข้อมูลโครงการ HR แล้วพบรุ่น 1.9.0 หน่วยงานเปิดใช้งาน 8 แห่ง บัญชี admin เปิดใช้งาน 1 บัญชี และช่องข้อมูลใหม่ครบทั้ง 6 ช่อง
- ทดสอบหน้าเบราว์เซอร์กับแม่แบบเปล่าแล้วปฏิเสธการบันทึกตามที่ควรเป็น การทดสอบไฟล์ที่กรอกข้อมูลผ่านเบราว์เซอร์หยุดระหว่างดำเนินการ จึงใช้ผลทดสอบตัวอ่านไฟล์และเส้นทางยืนยันบันทึกอัตโนมัติประกอบ
- ไม่ได้นำข้อมูลตัวอย่างเข้าฐานข้อมูลจริง และยังไม่ได้เข้าสู่ระบบด้วยรหัสผ่านของคุณหรือทดสอบ Google Drive/Sheets แทนคุณ
